# JIMTOF2026 非公式ガイド（Androidアプリ）

JIMTOF2026（第33回 日本国際工作機械見本市、2026年10月26日〜31日・東京ビッグサイト）の来場者向けガイドです。
主催者とは関係のない**非公式アプリ**です。データはアプリに同梱しているので、会場で電波が弱くても見られます。

## できること

| タブ | 内容 |
|---|---|
| 概要 | 開幕までのカウントダウン／開催中は「閉場まであと◯分」。会期と開場時間（最終日は16:00まで）、入場料、来場者証の注意、期限つきのお知らせ |
| ホール | 小間番号（例：E1024、WA015）を入れると、どのホールの何階かを表示。ホールごとの出展分野と企画、公式の小間割図（HTML・PDF）へのリンク |
| 予定 | 基調講演・特別講演・INSIGHTSステージ・IMEC・出展者ワークショップなど81件を日付別・種類別に表示。ベルを押すと開始15分前に通知 |
| マイリスト | 回りたいブース（会社名・小間番号・メモ）を登録。東→西→南のホール順に並び、訪問済みをチェック。テキストで共有も可。データは端末内だけに保存 |
| リンク | アクセス、来場登録・マイページ、出展者検索、JIMTOF Guide & Map、講演の公式ページ、問い合わせ先 |

## インストール

1. GitHub の **Releases** から最新の `JIMTOF2026Guide-buildN.apk` をスマホでダウンロードします。
2. ダウンロードしたAPKを開きます。「提供元不明のアプリ」の確認が出たら、ブラウザ（またはファイルアプリ）にインストールを許可します。
3. 新しいビルドは、同じ手順で上書きインストールできます（マイリストと通知設定は残ります）。

対応OS：Android 8.0 以上

## ビルド

- **GitHub Actions**：`main` ブランチに push すると自動でビルドし、テストのうえ Releases にAPKを添付します（`.github/workflows/build.yml`）。ビルド結果とログは `build-output` ブランチにも置かれます。
- **Android Studio**：このフォルダを開いて［Build］→［Build App Bundle(s) / APK(s)］→［Build APK(s)］。

## データの更新

講演の変更などは `app/src/main/assets/jimtof2026.json` を書き換えて push すれば反映されます。
`app/src/test/.../FairDataTest.kt` が、日付・時刻・IDの重複・URLの形式をビルド時に自動チェックします。

## 署名鍵について

`keystore/guide.keystore` は個人配布用の鍵です（上書きインストールのために固定しています）。Google Play で公開する場合は、新しい鍵を作り直してください。
