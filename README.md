# JIMTOF2026 非公式ガイド（Android）

JIMTOF2026（第33回 日本国際工作機械見本市、2026年10月26日〜31日・東京ビッグサイト）を回るための、**個人が作った非公式の Android アプリ**です。
主催者・出展社とは関係ありません。データはすべてアプリに入っているので、電波の弱い会場でも使えます。

> **ダウンロード**：このページ右側の **[Releases](../../releases)** から、いちばん新しい `JIMTOF2026Guide-buildN.apk` を保存してください。

## できること

- **担当の切り替え**：最初に担当を選びます（あとから右上の「i」→「担当を切り替える」、またはレポートタブの「切り替え」で変更）。
  - 立旋盤メーカー視点：①競合 ②省人化・無人化 ⑤展示方法
  - 西展示棟担当：①切削工具 ②保持具 ③測定機器
  担当ごとにレポートの項目・おすすめの会社・検索の候補・ルートの出発地点が変わります。書いたメモは担当ごとに残ります。
- **見学レポート**：項目ごとに、おすすめの会社と公開情報から分かった見どころ、ブースで確かめることを表示。その場でメモし、項目ごとの「まとめ」と合わせて下書きテキストとして共有できます。各社のカードから「マップで見る」で小間の場所へ。「ルート」では歩く時間が短い順の回り方と、回れる日数に合わせたプランを出します。
- **会場マップ**：公式の小間割図から写した全946小間の形を、ホールごとに描きます（地図の画像は使っていません）。レポートのおすすめ（①②…）とブースリスト（★）の会社に印をつけ、小間をタップするとその小間の出展社と見どころ・確かめることが出ます。指2本で拡大・移動。広げた画面（フォルダブルの内側など、横幅 600dp 以上）では図と一覧を横に並べます。
- **ブース（回りたいブース）**：東→西→南の順に並べて、訪問済みをチェック。ブースごとの「確かめること」はカードの「確かめることを足す」でその場で追加でき（定番・レポートの確認事項から選ぶか、自分で書く）、「マップで見る」で場所を確認できます。
- **出展社の検索**（1,139社）：社名・英語名・製品名・小間番号で探せます。表記ゆれ・打ち間違いも「近い表記」として拾います。結果から「マップで見る」で場所へ。ノベルティありの絞り込み、担当に合わせた見学テーマの候補つき。
- **予定**：基調講演・特別講演・INSIGHTSステージ・出展者ワークショップなど81件を日付別に表示。開始15分前の通知も設定できます。
- **会期・入場・アクセス**：右上の「i」から。入場料や来場者証の注意、アクセス、公式ページへのリンク。

## インストール（Android 8.0 以上）

1. スマホのブラウザで [Releases](../../releases) を開き、最新の APK をダウンロードします。
2. ダウンロードした APK を開きます。「提供元不明のアプリ」の確認が出たら、ブラウザ（またはファイルアプリ）のインストールを許可してください。
3. 新しいビルドは、同じ手順で**上書きインストール**できます（ブースリストと通知の設定は残ります）。

Google Play の配信ではないため、Play プロテクトの警告が出ることがあります。気になる場合は、このリポジトリのソースから自分でビルドすることもできます。

## プライバシー

- アプリは通信しません（インターネットの権限を持っていません）。リンクを押したときだけ、ブラウザが開きます。
- ブースリスト・メモ・ノベルティの記録は、**端末の中だけ**に保存されます。アカウント登録や広告・解析もありません。
- 通知のために、通知・アラームの権限を使います。

## ご注意

- **非公式**です。内容は 2026年10月26日 に確認した公開情報の写しで、会期中の変更は反映されません。最新情報は [JIMTOF 公式サイト](https://www.jimtof.org/jp/) でご確認ください。
- 出展社データは、公式オンラインカタログの「社名・小間番号・出展製品分類」だけを書き写したものです（説明文・画像・連絡先は含みません）。
- ノベルティは**全社分ではありません**。企業の告知と第三者のまとめから確認できた会社だけで、先着・数量限定のものが多く、配り終えていることもあります。ここに無い会社にノベルティが無いとは限りません。
- 「見学レポート」のおすすめは、公式カタログの出展製品分類と各社の一般的な製品分野から選んだものです。各社の JIMTOF2026 の展示内容は、公式サイトの出展者情報ページと各社の案内（2026年10月30日 時点）を短くまとめたもので、55社中50社に付けています。実際の展示は会場で確認してください。「検索」タブの候補は、会社が登録した分類による機械的な絞り込みで、提案内容そのものを調べたものではありません。
- 実機での動作確認は限られています。表示の不具合や誤りは [Issues](../../issues) へ。権利者の方からの削除・修正のご依頼も、Issues でお受けします。
- 「JIMTOF」は主催者の名称です。このアプリはその名称を、対象の展示会を示す目的でのみ使っています。

## 開発者向け

Kotlin 2.0 / Jetpack Compose（Material 3）。minSdk 26、targetSdk 35。

### ビルド

- **GitHub Actions**：`main` に push すると自動でビルド・テストし、Releases に APK を添付します（`.github/workflows/build.yml`）。結果とログは `build-output` ブランチにも置かれます。画面の確認用に、エミュレータでスクリーンショットを撮る手動実行の `ui-check.yml` もあります。
- **Android Studio**：このフォルダを開いて［Build］→［Build App Bundle(s) / APK(s)］→［Build APK(s)］。

### データの更新

- 講演・お知らせ：`app/src/main/assets/jimtof2026.json` を書き換えて push。`FairDataTest` が日付・時刻・IDの重複・URLの形式を自動チェックします。
- 出展社：`app/src/main/assets/exhibitors.json` は `tools/raw/` のテキストから `python3 tools/build_exhibitors.py` で生成します。
- ノベルティ：`app/src/main/assets/novelty.json`。会社ごとに品名・条件・数量・出典を手で書き、社名と最初の小間番号で出展社データに結びつけます（`NoveltyTest` が突き合わせを確認）。
- 見学テーマの候補：`logic/ReportPreset.kt`（出展製品分類の重みづけで機械的に拾います）。
- 会場マップ：`app/src/main/assets/booth_map.json` は `python3 tools/fetch_booth_map.py`（GitHub Actions の `fetch-map.yml` で実行）が公式の小間割図（`*-BoothInfo.js`）から小間番号・形・印の位置だけを取り出して作ります。描画は `ui/MapScreen.kt`、印は `logic/MapMarks.kt`。テストは `ProfileAndMapTest`。
- 担当：`data/ViewerProfile.kt`。次の展示会では担当を足し、`report_*.json` を差し替えます。
- 見学ルートの略図：`ui/components/RouteMap.kt`（ホールを1つずつ描き、日ごとの順路を矢印と番号で重ねる）。
- 見学ルート：`logic/VenueWalk.kt`（ホールの位置と歩く時間の目安。東4〜6は休館なので無し）と `logic/RoutePlanner.kt`（出発地点から全ホールを回る最短の順番を部分集合ごとの最短で厳密に解き、同じホールの中は小間番号順。1日の持ち時間で日に分ける）。テストは `RoutePlannerTest`。
- 見学レポートのおすすめ：`app/src/main/assets/report_west.json`（西展示棟担当）は `python3 tools/build_report_west.py` で生成します。`report_oshima.json`（立旋盤メーカー視点）は手で書いたもの。社名・小間番号・出展製品分類は出展社データから、理由・主力・確かめることは同スクリプトに手で書き、各社の JIMTOF2026 の展示内容は `tools/make_report_west_facts.py`（公式サイトの出展者情報ページと各社の案内を 2026年10月30日 に読んで短くまとめたもの）が `tools/report_west_facts.json` を作り、出典つきで足します（`ReportTest` が出展社データと突き合わせ）。実際の展示は会場で確認してください。
- 出展社検索：`logic/ExhibitorSearch.kt`。表記ゆれの吸収、語ごとの得点づけ、複数語は AND。ぴったり合う会社が10社未満のときは、濁点・小さい文字をそろえた形での一致と、語の長さに応じた文字数（4〜5文字で1、6〜8文字で2、9文字以上で3）までの違い（置換・抜け・余分・隣の入れ替え）を「近い表記」として低い得点で足す。テストは `ExhibitorSearchTest`。

### デザインの方針

- 文字と地の色の組み合わせは WCAG AA（コントラスト比 4.5:1 以上）を満たすものだけを使う（`ui/theme/Theme.kt`）
- 場所を表す色は画面をまたいで統一（東＝青、西＝緑、南＝橙、会議棟＝紫）。色だけに頼らず E/W/S の文字を必ず添える
- 本文 15〜16sp・行間 1.5 倍、押す部分は 48dp 以上、余白は 8dp の倍数

### 署名鍵について

`keystore/guide.keystore` は個人配布用の鍵で、上書きインストールのためにリポジトリに入れています。**秘密の鍵ではない**ので、この鍵で署名した APK は本物の証明になりません。Google Play で公開する場合や、広く配る場合は、新しい鍵を作り直して Secrets に置いてください。
